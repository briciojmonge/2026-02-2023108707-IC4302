## Respuestas:

1. El término viene de la tería de ingeniería de control, se refiere a automatizar el control de un sistema dinámico para que su dinamicidad se mantenga en un nivel deseable. De modo quq permite saber el estado del sistema según la cantidad de métricas y el significado de estas. 

2. La lectura expone varias rasones para crear aplicaciones observables, como: la gran cantidad de cosas que pueden fallar en un ambiente complejo pero un sistema observable permite saber que componente falla exactamente, la segunda razón es la agilidad con la que las apps se despliegan y ya que se hacen despliegues constantes la observabilidad puede ayudar a saber que salió mal,la tercera es la brecha de abilidades, y la expectativa de que las apps tengan uptimes casi completos.

3. 
  **Métricas:** el tipo más común de métricas y valores disponible para los sistemas. normalmente son datos con un punto en el teimpo, que pueden ser calculados, agregados, o promediados. Se pueden obtener de la infreaestructura de un sistema. 
  **Logs y Eventos:** los eventos son las interacciones y lo que pasa dentro de las apps, y los logs son registros detallados de los eventos. los Logs dan registros paso por paso de cada componente y cada uno de estos con un tiempo único.
  **Traces:** registran los "caminos" de extremo a extremo de cada llamada dentro de una arquitectura distribuida. registran las transacciones generadas por la app o por los usuarios.

4. Buenas prácticas de observabilidad:
- Identificar una serie de etiquetas para añadirle a cada recurso.
- Recolectar tantas métricas como sea posible de cada componente de la app.
- Agregar, promediar o crear porcentiles las metricas cómo se necesite.
- Encargarse de activar el logging.
- Los logs deben configurarse apra que exponangan cierta metadata.
- Usar instrumentación en apps para trazabilidad.
- Identificar transacciones clave y workflows.
- Identificar un set de alertas y sus alcances.

5. APM consiste de dos signifcados, Application performance management o application performance monitoring:
 El primer significado se refiere a la revsión constante de la experiencia de usuario, el rendimiento, el patrón de uso, la disponibilidad y las dendencias. Busca detectar automáticamente anomalias y problemas para encontrar la causa. Y, El segundo significado se refiere a lo que muestra el rendimiento de una app o web en términos de diferentes métricas/dimensiones. esta relacionado al proceso de recolleccion de datos y la presentación  de estos.
